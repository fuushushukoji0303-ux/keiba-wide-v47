地方競馬ワイド投票管理 v47 スマホ完全版

【v46からの追加】
1. NAR公式サイトからワイドオッズを取得
2. 単勝・複勝データも取得
3. PC版v44のロジックをベースに3点候補を表示
4. 堅め / バランス / 穴狙い の3モード
5. 参考ランク S+ / S / S- / A / B / 見送り
6. 3点候補をホームへ自動入力
7. S/A系の分析結果を「今日の勝負レース」に保存
8. 購入記録・的中/ハズレ・払戻・収支管理

【Render】
Build Command:
pip install -r requirements.txt

Start Command:
gunicorn app:app

【重要】
無料Renderでは永続ディスクを使えません。
再デプロイや環境再作成でSQLiteの履歴が消える可能性があります。
安定運用時は外部DBまたは有料永続ディスクへの移行を推奨します。

【投票】
このアプリから自動投票はしません。
SPAT4公式サイトを開き、最終確認・投票は利用者自身が行ってください。

【予想について】
3点候補と参考ランクは市場オッズを使ったルールベースの参考情報です。
的中や利益を保証するものではありません。
